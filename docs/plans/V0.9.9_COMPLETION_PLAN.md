# v0.9.9 completion plan

Owner correction recorded 2026-09-28. v0.9.8 was published while the current demo
and substantial documentation/enablement work remained unfinished. Labeling the
old video historical did not fulfill the requested refresh. This release closes
those gaps first, then completes the original v0.9.9 deliverables.

## Ordered acceptance gates

| Order | Deliverable | Evidence required before completion |
|---|---|---|
| 1 | Reconcile every original instruction | Requirement-by-requirement checklist with artifact paths and limits |
| 2 | Complete current product story and user documentation | Full operator routes, scientific process and SAT exercises, architecture/workflow/visual examples, current screenshots, expert and newcomer review corrections |
| 3 | Replace the current demo | Actual current synthetic-case UI, narration, captions, transcript, poster, verified playback and current guide links |
| 4 | Implementation and infrastructure | Install/upgrade, data migration, topology, real runtime/build requirements, optional services, capacity evidence and operational acceptance |
| 5 | Operations, maintenance, automation | Task owners, cadence, exact commands, backups/restores, dependency/version checks, recovery and monitoring contracts |
| 6 | Public marketing materials | Audience pitches, product explanation, LinkedIn, Mastodon, Signal share, jarocki.org website copy; tracked and not ignored |
| 7 | Qualification | All Python/browser tests, docs links, media/codecs/captions, CLI/install paths, locks/audits, release guard, editorial evidence |
| 8 | Publication | Public main and matching tag, immutable artifacts, owner signature, downloaded verification receipt |

Every row must have a concrete result. A version bump, planned filename, historical
screenshot, or passing link checker alone does not complete a row. Marketing posts
and website content are repository deliverables; outbound posting is a separate
action requiring the owner's chosen destination and authorization.

The 1.0.0 final assurance pass and owner approval remain future release gates.

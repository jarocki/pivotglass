# v1.3.0 web cockpit critique and response

Date: 2026-11-15. Tracking: #24, #25, #26, #27.

Eight reviewers critiqued the cockpit independently from screenshots at 1920, 1440 and 390 px, with the source in hand. Each had one lens:

- an ADHD analyst
- an autistic analyst
- a dyslexic analyst
- a low-vision, migraine-prone principal analyst
- a cognitive psychologist (sensemaking, cognitive load, analytic bias)
- a product visual designer
- an interaction designer and information architect
- an impatient senior CTI analyst

The owner set the brief: make the cockpit fast, lean, beautiful and actionable; stop the squinting; let the main view go wide; let panes pop out; cut the busyness.

## Consensus (raised by five or more reviewers)

| Finding | Evidence | Response in v1.3.0 |
|---|---|---|
| Text is too small to read. 226 of 304 `font-size` declarations were under 12 px, down to 6 px. | `pivotglass.css` | All interface type is now set in rem against one root size. Nothing renders below 12 px at the standard setting. |
| "Larger text" missed most elements. It used a selector list with `!important`, and px sizes ignored the browser default. | `pivotglass.css:1053` | One text-size preference with four steps changes the root size. It also scales the source-review frame. The old patch rules are deleted. |
| An unasked guidance popover blurs the page, and a second "Novice practice" band duplicates it. | `page.tsx:1159`, `pivotglass.css:998` | The band is removed. Guidance opens only from Help. The blur and dimming are removed. |
| A missing API key is shown as a failure: "16 needs attention", red cells, and the brief's main call to action. | `server.py` failure path | An enrichment whose only problem is a missing key is recorded as *not configured* (skipped). It is not a source fault and does not raise attention. |
| Motion, flicker and glow run by default. | `page.tsx:328`, lamp flicker keyframes | The default is now Reduced. The idle flicker is gone, and glow and grid effects appear only with Full. |
| The fixed 1180 px column wastes wide screens. The same width rule existed in three places. | `pivotglass.css:779,990,1002` | A single `--main-width` set by the width preference: Column, Wide (default) or Full. |
| Maximize existed for three panes, and Sources was not one of them. | `PanelTitle` | One pane header for every pane, with Maximize (in-page; Esc restores) and Pop out (its own window). The maximized Sources pane is a full-height intake. |
| Duplicate and decorative chrome. | masthead | The DECK button, focus-zone pill, second lamp, footer Help, permanent hint line, "PYTHON INTENT / FLINT", "AWAITING TARGET LOCK" art, and "Cockpit link established" are all removed. |
| Vocabulary drift: "focus" had four meanings, and the Evidence area had three names. | various | Tabs, menu and pane titles now share one label each. "Focus mode" means only indicator focus mode, the owner's term. |
| Indicator values could not be copied, and hashes broke at arbitrary characters. | `indicator-focus.tsx` | Added copy actions (`c` for the current indicator; `y` and `Y` for the selection, defanged and refanged). Hashes are displayed in groups of 8 and still copy raw. |

## Decisions on reviewer conflicts

- **Hover card translucency.** The owner asked for a translucent on-hover popup. Three reviewers asked for it to be opaque because the table ghosts through it. Resolution: it stays translucent, but at 94% surface opacity with a stronger blur. Text is at least 12 px, and the card is positioned so it does not cover the hovered mention. The `i` key still pins details.
- **Personas.** Reviewers asked to hide persona chrome. Personas are durable, so they remain. Narration now defaults to Brief, and the persona voice strip shows only with Full narration. Personas no longer restyle pane borders.
- **Evidence versus inference.** Reviewers asked to drop the verbal disclaimers. The repository rule requires the distinction to remain visible. The guidance surfaces now carry a compact "Guidance" chip and a distinct style instead of a sentence.

## Deferred, with issues

These are larger capability changes, not cleanup, and are tracked for v1.4.0:

- Per-indicator pivot sheet: resolutions, certificates, WHOIS, hosting/ASN, JARM and favicon, with co-occurrence counts. Tracked in #21 and #22.
- Triage provenance in the focus list (first seen, which source, prior tags, known-noise ranges), plus a "pivot every new indicator" action.
- Suggested clusters from shared pivot values. The analyst accepts or rejects each one, and it is recorded with its evidence.
- An attack-path lane view by ATT&CK tactic, and technique-level tags.
- Tabs that own the main area. An indicator table grouped by cluster and role, with competing hypotheses on the main view.
- Exporting the filtered selection from focus mode.
- A dossier list to replace the hex grid.

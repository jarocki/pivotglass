# Pivotglass v0.9.1 to v1.0 burndown

This plan keeps the remaining work small enough to verify and release. A target
version is a scheduling boundary, not a claim that the work is complete.

## v0.9.1 — Analyst Flow

- Make the focused, single-column investigation view the default.
- Put the current question, recent change, separate progress measures, open
  gaps, and one deterministic next action in the first viewport.
- Keep all expert analysis, configuration, visualization, and presentation
  controls available through four primary destinations.
- Verify phone, laptop, Day, Night, keyboard, and no-overflow behavior.

## v0.9.2 — Evidence clusters

- Summarize connected components of admitted graph edges as evidence or
  activity clusters with stable identifiers.
- Show contributing entities, edge truth classes, provenance diversity,
  first/last observed time, mapped behaviors, and Dossier gaps.
- Never turn a cluster into an actor attribution without an explicit,
  sourced analyst judgment and formal confidence.

## v0.9.3 — Longitudinal tracking

- Track cluster changes across investigation sessions without rewriting prior
  evidence.
- Highlight added, removed, conflicting, and reclassified entities and
  relationships.
- Add reviewed SCOT session-publication views and Synapse-backed graph
  comparison where the configured authority is available.

## v0.9.4 — Candidate behavior review

- Compare observed behavior with the pinned ATT&CK, Kill Chain, and Diamond
  perspectives.
- Present unmatched behavior as a candidate behavior or framework gap, not an
  automatically discovered TTP.
- Require evidence references, alternative explanations, analyst disposition,
  and confidence rationale before materialization or publication.

## v0.9.5 — Usability and accessibility closure

- Run novice, working analyst, and expert task walkthroughs at phone, laptop,
  and desktop widths.
- Measure time to start an investigation, find the next action, inspect
  provenance, resolve a contradiction, pivot, and export a report.
- Close keyboard, screen-reader, contrast, focus restoration, reduced-motion,
  terminology, and low-light issues.
- Remove or combine controls that do not improve task completion while keeping
  command and expert-workbench access.

## v1.0.0 — Public release gate

- No unresolved critical or high security findings.
- Evidence, inference, proposals, narration, and presentation remain visibly
  distinct in every interface and export.
- Existing workspaces migrate forward with backup-first recovery.
- Full Python, web, package, release-contract, browser, accessibility, and
  supply-chain verification passes from a clean checkout.
- Installation, first investigation, graph review, model configuration,
  integrations, reporting, and recovery documentation matches the executable
  product.

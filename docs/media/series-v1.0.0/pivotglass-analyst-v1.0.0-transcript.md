## 00:01:08.475 — Test the reasoning

Link evidence to a hypothesis with an explicit stance and rationale. The competing-hypotheses matrix lets us compare the same evidence across alternatives. Then record a structured technique run: inputs, analysis, limitations, and disposition. Required fields make the work inspectable; the analyst still evaluates the argument.

## 00:01:27.729 — See what is missing

Coverage shows where the investigation has evidence and where it needs more. It does not measure danger. Likelihood asks how probable an explanation is. Confidence asks how sound and sufficient its evidence and reasoning are. Keep the collection requirement and stopping condition visible so the hunt has a purpose and a boundary.

## 00:01:45.763 — A defensible handoff

Generate the workspace report. Review questions, alternatives, explicit evidence links, technique results, unresolved contradictions, and next steps. Save Markdown for an editable handoff, or print to PDF. Before sharing, check source handling and limitations. The next analyst should be able to reconstruct the case, challenge the judgment, and continue the work.

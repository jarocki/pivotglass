I built Pivotglass to help cyber defenders level up. Analysts have to work
through incomplete data, make careful decisions, and leave behind reasoning
that another person can check. Too often, that work gets scattered across
tools, tabs, and notes.

Pivotglass is my attempt to make the job faster and easier to accomplish while
keeping it rigorous. It's an AI-augmented framework with repeatable workflows:
start with a question, review a source, choose what to admit, pivot through the
relationships, test competing explanations, and produce a report with the
evidence and uncertainty still visible.

The provenance history shows how you got there. Relationship views distinguish
stored links, property pivots, and indicators grouped by an analyst. Structured
Analytic Techniques help expose assumptions and contradictions. A Novice Q&A
helps newer analysts practice asking better investigative questions. None of
those features turns a model's answer into evidence or takes the final judgment
away from the analyst.

My goal is straightforward: help defenders do good analytical work more
consistently, learn while doing it, and produce results they can verify and
hand off. You can run the synthetic learning case locally without API keys.

I made a short Overview video showing the interface and the workflow. If this
sounds useful, try Pivotglass and tell me what works and what needs work.

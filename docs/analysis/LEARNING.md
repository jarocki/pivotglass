# Learn through real investigative practice

[Analytic method](README.md) · [Offline worked example](WORKED_EXAMPLE.md) · [User guide](../USER_GUIDE.md)

Novice Mode supports learning while doing the work. It slows question framing
into manageable prompts, explains why each prompt matters, and leaves room to
say “I don't know yet.” The purpose is to develop habits that remain useful when
the guidance is reduced: source checking, scope control, competing explanations,
and explicit uncertainty.

## Six prompts, six analytical habits

| Prompt | Habit to practice | A mentor's follow-up |
| --- | --- | --- |
| What data do you have? | Name provenance before conclusions | Who collected it, when, and from which independent source? |
| What happened? | Separate reported observations from suspicion | Which exact record supports that description? |
| Do you know how it started? | Distinguish earliest visible from initial event | What earlier activity might be outside sensor coverage? |
| Who or what is affected, and when? | Bound scope and time | Which affected systems are supported versus assumed? |
| What decision must this support? | Connect analysis to an action | What finding would justify containment or more collection? |
| What else could explain this? | Seek discriminating evidence | What would weaken your first explanation? |

## Use the Q&A deliberately

Open the Scientific Notebook in Novice guidance. Answer one prompt at a time,
or select **I DON'T KNOW YET**. Use **BACK** to revise context and **PAUSE Q&A**
to stop without saving notebook questions. Review the three drafted questions,
edit their scope and wording, and select **SAVE THIS QUESTION** only for the
questions useful to the active investigation.

Answers are reported context awaiting source checks. A draft is neither an
observation nor an accepted hypothesis. Saving a question uses the ordinary
analytic ledger command; it does not start collection or accept a finding.

The draft, answers, reflection, and saved-question flags are browser-local and
scoped by workspace name. Saved notebook questions persist in the workspace
database. A different browser will not automatically have the local draft.
Clear local context on a shared browser when appropriate. Clearing a draft does
not delete saved questions. If a save response is interrupted, inspect the
notebook before retrying so a duplicated question is not mistaken for new work.

## Build skill over repeated cases

The coach requires at least one reviewed saved question and a written reflection
before recording a completed practice session. Rotating lessons emphasize
provenance, disconfirmation, scope, and decision relevance. After several
sessions, it suggests trying the next framing independently. The analyst chooses
Novice, Adept, or Expert in Help; there is no automatic graduation.

A useful practice sequence is:

1. **Supported framing:** complete the Q&A and identify what is unknown.
2. **Independent framing:** write a question first, then compare it with the prompts.
3. **Alternative explanations:** name two plausible answers and a discriminating observation.
4. **Source review:** trace one conclusion to its observations and dependence groups.
5. **Challenge:** use a Key Assumptions Check or Devil's Advocacy run.
6. **Handoff:** ask a colleague to reconstruct the conclusion and unresolved gaps from the report.

These are training exercises, not an automatic application curriculum or a
qualification rubric. A mentor can use the persisted notebook and method runs
to discuss reasoning without relying on the learner's memory of the session.

## Reflection prompts for a reviewer or mentor

- Did the question presume the answer?
- Could the evidence distinguish the leading and alternative explanations?
- Were apparently independent reports derived from the same source?
- Did the analyst confuse collection time with event time?
- What finding would change the decision?
- Is the confidence basis complete, and are unknown factors explicit?
- Can another analyst follow the record without asking for the whole story again?

Feedback should address the reasoning and next skill to practice. Reward an
accurate “unknown” and a useful collection requirement, rather than pressure to
produce a confident conclusion. The first goal is reliable judgment; speed can
follow familiarity and better organization. Claims about improved speed or
competence require separate observation and evaluation.

# Pivotglass v0.9.7 early-availability announcement kit

These drafts describe the implemented v0.9.7 behavior. Keep the release marked
early availability and link to the public repository after the release is
published.

## LinkedIn

An indicator is not the answer. It is the first node.

Pivotglass is a local-first cyber-threat investigation workspace built around a
simple idea: analysts should spend less time moving between disconnected tools
and more time testing what the evidence actually supports.

Start with an indicator, a list, or a report. Pivotglass previews documents
locally, lets the analyst choose which candidate entities to admit, preserves
source and parser provenance, enriches through configured intelligence
services, exposes contradictions and coverage gaps, and turns supported
relationships into a defensible graph and report. Models can explain or
propose; they do not own analytical truth.

The v0.9.7 early-availability release moves report and indicator-list intake to
the start of the Investigate workflow and adds graduated, task-relative
guidance for new users. A built-in synthetic learning workspace requires no API
keys and no live target.

Repository: https://github.com/jarocki/pivotglass

## Hacker News / Reddit

**Title:** Show HN: Pivotglass – a local-first, evidence-grounded threat investigation workspace

Pivotglass helps an analyst move from one clue to sourced evidence, supported
relationships, visible gaps, justified pivots, and a defensible report without
hiding those steps behind a model response.

The browser cockpit and terminal interfaces share the same local workspace.
Document preview is bounded and non-persistent; candidate entities require an
explicit analyst selection before admission. Graph edges retain provenance and
truth class. Contradictions, missing Dossier dimensions, and incomplete
scientific-method steps stay visible. AI may summarize or propose, but
deterministic code and direct APIs own state and evidence.

The repository includes a synthetic learning workspace that runs without API
keys or a live indicator. Feedback on analyst workflow, provenance boundaries,
and the pre-1.0 release gates is especially welcome.

https://github.com/jarocki/pivotglass

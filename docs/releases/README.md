# Release history and qualification records

Each version directory preserves its dated release notes, QA receipts, and
handoffs. Historical receipts describe the version tested at that time; they
are not current capability or v0.9.8 test claims. Retired executable/package names
use explicitly labeled historical placeholders. Use the [current Quick Start](../QUICKSTART.md)
for executable installation commands.

The [v0.9.8 preparation plan](../plans/V0.9.8_RELEASE_PLAN.md) records the current
scope, verification gates, and changes. The [release roadmap](../plans/V0.9.8_TO_1.0_ROADMAP.md)
distinguishes v0.9.9 enablement work from the approval-gated v1.0.0 assurance pass.
